Faixa de largura total que organiza a tela. A troca de cor entre tiles é o divisor: sem linha, sem sombra, sem canto arredondado.

- **Claro:** `canvas`. **Parchment:** `canvas-parchment`, para quebrar dois tiles brancos seguidos. **Escuro:** `surface-tile-1`, texto `body-on-dark`, links `primary-on-dark`.
- Conteúdo: título (`display-lg`, 34px no celular), uma linha de apoio (`lead`) e, no máximo, duas ações em pílula.
- Use o tile escuro para o dado que decide a tela: total do orçamento, valor a receber, faturamento do período.
