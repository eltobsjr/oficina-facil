Cartão utilitário e item de lista.

- **Cartão:** fundo `canvas`, filete de 1px `hairline`, `radius-lg`, padding `space-lg`. Sem sombra.
- **Item de lista:** linha de 72px, nome em `body-strong`, apoio em `caption` com `ink-muted-80`, valor alinhado à direita com números tabulares.
- **Inativo:** texto em `ink-muted-80` e chip "Inativo"; não use opacidade para sinalizar estado.
- **Alerta de estoque:** chip com `danger` sobre `danger-surface`, nunca só a cor: sempre com o texto.
